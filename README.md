# Задачи сотрудников

Веб-страница на React и TypeScript. На ней можно добавлять задачи, менять их статус и фильтровать список по сотруднику. Просроченные задачи выделяются, а данные сохраняются в `localStorage` браузера.

[Открыть демо на GitHub Pages](https://altulin.github.io/gorstroy-test/)

## Запуск

```sh
npm install
npm run dev
```

Откройте [страницу](http://127.0.0.1:3000/). API и файл `.env` для запуска не нужны.
